TrackCM

TrackCM is an enterprise multi-tenant Campaign & Conversion Intelligence Platform. It provides marketing and growth engineering teams with visual drag-and-drop landing page composition, automated lead capture pipelines, and sub-second analytics attribution while maintaining rigorous tenant data isolation.

Multi-Tenant Isolation Row-Level Security (RLS) with SESSION_CONTEXT in Azure SQL Database
Drag-and-Drop CMS Dynamic Angular 19 component outlet with real-time reactive signals
Attribution Engine Full-funnel conversion tracking, UTM touchpoint logs, and cohort analysis
Cloud Infrastructure Containerized .NET 8 Web API on Azure App Service with Redis distributed cache
  • Database-Level Isolation: Complete tenant protection via Azure SQL row-level security predicates and tenant-aware DbContext dispatching.
  • Dynamic Block Hydration: Modular visual block builder with real-time DOM hydration, reusable marketing sections, and atomic design tokens.
  • High-Velocity Event Ingestion: Pipeline processing page interactions, form submissions, and multi-step drop-offs with Redis distributed caching.
  • Enterprise Identity & RBAC: Seamless Azure AD B2C integration supporting OAuth 2.0 / OIDC with granular role permissions.

Native iOS App · SwiftUI · 2026 Interactive Simulator

GoldTracker

A native SwiftUI iOS application engineered to monitor live market spot prices for gold, silver, and platinum. Built using the MVVM pattern with async/await concurrency, interactive historical sparklines, and precision numerical normalization.

  • Asynchronous REST Streaming: Live spot market rates fetched via Swift async/await with robust error handling and pull-to-refresh.
  • MVVM Architecture: Clean unidirectional data flow decoupling view rendering from price calculations and time-series normalization.
  • Interactive Charts: Dynamic 1D / 1W / 1M / 1Y historical range calculations with custom SwiftUI path rendering.
  • Apple Design Polish: Dark/light mode fidelity, haptic feedback on asset tab switching, and native SF Symbols iconography.
